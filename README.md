# bakerlab
This is the home for all of the Baker Lab stuff\
A place to share any relevant scripts in a way that is easier to navigate than through directories in onDemand.\
\
Rules:\
\t  • Feel free to upload any new analysis scripts and update old ones if you have any major improvements,\
\t  but for the most part, if it ain't broke, don't fix it!\
\t  • Make sure all relevant scripts are organized into folders and named clearly.\
\t  • All new folders must have a readme detailing what it is for and use cases.\
\t  • Avoid redundant scripts -- no need to create a new file if only the parameters are different. Look around \
\t  before committing.\
\t  • Include comments throughout code explaining what it does (doesn't need to be too detailed, mainly try \
\t  to outline what people will need to change for their files)\
\t  • Use placeholder names for any files specific to your directory setup.\
\t  • Only upload into the scripts folder for your relevant projects.\
